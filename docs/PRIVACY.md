# 隐私与会话

- Cookie 相当于登录凭据。导入只读取用户选择的文本/文件；按平台域名过滤，网络请求重新按域名/路径/secure/过期时间选择 Cookie。
- 账号存储使用 Android Keystore 的 AES-GCM；设置、任务和会话位于 noBackup 区域；Manifest 关闭应用备份。
- 引擎进程需要临时 Netscape Cookie 文件，位于应用私有目录、仅当前用户读写，正常退出会删除；下次初始化也清理残留。因此不能把“加密存储”误称为“任何时刻都没有明文”。
- 官方 WebView 使用单独进程/数据目录，不注入 JS，不加桥接对象，不截取密码，不忽略证书错误，不允许 file/content 跳转。用户确认后才导入 Cookie，保存不等于身份验证。
- 没有统计 SDK、第三方解析服务器、内置账号、日志上传或在未点击时读剪贴板。
- 错误信息经过分类，不把可能包含 Cookie 的引擎原始 stderr 写到日志或弹窗。发布前应进一步做凭据和 Intent 边界审计。
- MediaStore 删除只接受本机账本记录的 content URI 所属提供者。应用数据丢失/重装后的旧文件不应冒充仍由此账本管理。

请不要把自己的 cookies.txt、凭据截图、Keystore 或账号刷新令牌提交进 Git 仓库，或随编译报错发给其他人。
