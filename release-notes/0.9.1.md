# 镜流 0.9.1 · 液态玻璃交互与光学升级

在 0.9.0（底栏按压拖动、页面联动、开关/滑块镜片、独立设置玻璃）基础上，补齐液态套件：

- 底部导航长按/按住滑动/跨页连续拖动，选中镜片跟手，页面与镜片连续联动；取消恢复起始页
- 按压放大、速度拉伸、阻尼弹簧、释放回弹，统一到按钮/图标/筛选/菜单
- 设置每个模块独立玻璃层，真实背景折射；Clear / Regular / Frost / 有色介质 + 实时材质预览
- 开关/滑块长按保持液态；输入/搜索焦点玻璃过渡；菜单/弹窗展开光学 swell
- 双镜片 smooth-min 黏连；QWEA 逆幂边缘折射；Kyant 圆弧透镜；RGB 边缘色散；边缘柔化
- 局部触摸鼓起；指针/重力双向镜面高光（横竖屏重映射、平放回退、低通，后台/省电/减少动态时停）
- 自适应明暗；背景饱和度保护；滚动顶部/底部渐进模糊（可关闭）
- 降级：API 33+ 镜片 / 31–32 模糊 / 26–30 实色；减少透明/动态/高对比/省电/着色器失败均回退
- 性能：共享 GlassSurface / shader / backdrop，无每帧 Bitmap、PixelCopy、大范围离屏、无限重绘与重复编译

边界：网页、二维码、视频画面、输入文字本身不做玻璃扭曲，只作用于镜流自有 UI 材质层。
业务（解析、下载、登录、Cookie、二维码、文件管理）逻辑未改。

参考：Kyant0/AndroidLiquidGlass（Apache-2.0，65ab177）圆弧透镜/色散/交互高光/阻尼；
QWEA0/Liquid-Glass-Android（MIT，73e2253）逆幂折射/SDF/smooth-min/鼓起/双向镜面/自适应/介质/饱和度。
本仓库为重新实现，未复制上游源码文件。

需真机验收：长按拖页、快速切页、多指取消、横屏平板、长列表滚动、账号登录、解析下载与帧时间。
