# 镜流 0.9.0 · 液态玻璃交互预览

本次源码改造包含底栏持续按压/横向拖动、页面连续位置联动、按压力度驱动的镜片折射、透明扩展式开关/滑块，以及独立分组的设置玻璃模块。

渲染分层保持“背景 → 轨道/底栏标签场景 → 镜片”，镜片不采样自身。默认保留减少动态效果、减少透明度、增加对比度和分区域玻璃开关。解析、下载、账号、Cookie 与二维码相关业务代码不在本次改动范围内。

完整镜片路径仍要求 Android 13 及以上及硬件加速；Android 12 使用背景模糊，Android 8–11 使用可读实色回退。本次没有移植 QWEA0 的旧系统 View/OpenGL 渲染后端，也没有宣称逐项复制两个演示应用的所有功能。

这是首轮预览，需真机验收：按住底栏不松手拖到另一个页面、反向拖回、多指/取消、开关和滑块持续按压、快速切页、滚动设置、横竖屏、深浅色与辅助功能。CI 无法证明 iOS 一致性或 120Hz 流畅度。
